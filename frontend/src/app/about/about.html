About StudentConnect

StudentConnect is a beginner-friendly school portal built to teach how modern web applications work — from the browser, to the frontend, to the backend, to the database, and eventually to the cloud.

The application is being developed step by step. It now has a full ASP.NET Core Web API backed by a PostgreSQL database, with JWT-based login and role-based access for Students, Teachers and Admins — covering attendance, marks, homework, learning materials and activities.

In later phases, StudentConnect will move its hosting, storage and identity onto Microsoft Azure, eventually running entirely in the cloud.
